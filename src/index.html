About this chart

A continuity map of the Transformers OG World — the main G1 line, from Beast Wars through the cartoon, comics and toy-era spin-offs — redrawn from a hand-drawn original. Arrows trace direct lineage: an adaptation, a sequel, a continuation.

Reading. Drag to pan; scroll or pinch to zoom. Click an entry for its details. Tags and references are the two tabs at the left edge: a tag's dot hides or shows what wears it, and a small raised number in any text opens the reference it cites.

Editing. The round + in the corner adds an entry — point at it and pick a style. Drag from one entry's edge to another to connect them, and double-click any text to write it where it stands. Shift while dragging lines things up, Ctrl takes them off the grid. Del deletes; Ctrl+Z and Ctrl+Y undo and redo; Ctrl+C, X and V copy, cut and paste.

Saving. Nothing is kept until Save (or Ctrl+S). The File button says where Save writes, and exports a self-contained copy of the page with the chart inside it.

Only the owner can change the chart; everyone else gets a read-only view. This is a draft, and will have errors and omissions.

Suggestions

This chart is read-only for you, and a page like this one can only be written to by its owner — so a suggestion typed here cannot save itself into the chart. Write it above, press Copy for the comment thread, and paste it into the comment control in the viewer around this page; it arrives already signed and labelled, and the owner can post it into the list below.

You own this chart, so Post adds a suggestion to the list straight away. It is stored with the chart and published the next time you press Save.

Choose the part to use

Drag inside the square to move it, or a corner to resize.

Stickers

A sticker is a small square picture you can drop into any text on the chart the way you would an emoji — an entry's label, a note, a language tab, a loose block of text. Use the ☺ button beside any text field to insert one.

Square images or GIFs. A still picture is shrunk to fit; an animated GIF is kept as it is, so keep those small.

This chart as a file

An exported page is the whole chart — drawing, editor and contents in one file. Open it anywhere, edit it, export it again; it needs no server and no account. Just the contents is the same entries without the page around them: a few kilobytes instead of a few hundred, for handing your work to someone rebuilding the page.
